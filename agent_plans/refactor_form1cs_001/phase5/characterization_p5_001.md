# P5-001 現行挙動 characterization

## 1. この文書の位置付け

Phase 5 で自動処理を分離する前の、現在の `Form1` の挙動を固定する。
ここでいう「互換維持」は望ましい仕様という意味ではなく、P5-003/P5-004 の移管時に
意図せず変更しないための基準である。例外、範囲外書き込み、Undo 履歴の巻き戻しなど、
安全性に関わる項目は **別修正** と明記し、host 導入時に原子的な拒否へ変更する。

表中のセル列は上から下への値を表し、`""` は空セル、`KARA` は
`Settings.KaraCell` と同じ文字列、`A:B` は隣接する2列を表す。

## 2. 共通観察事項

- 連番、置換、反転、四則演算は処理後に `FinishWriteOperation(true)` を呼ぶ。
  変更候補が0件でも再描画と `isFirstEdit = true` は行うが、
  `ApplyCellWrites` は空リストを group にしないため Undo 項目は増えない。
- 書き込みがある場合は機能名（`連番作成`、`置換`、`反転`、`四則演算`）の
  1 group となり、Undo 1回で戻り、Redo 1回で再適用される。
- 置換、反転、連番は選択の左端列だけを処理する。四則演算だけは選択矩形の全列を処理する。
- 数値の解析と計算は `Int32` で行う。既定の unchecked 演算のオーバーフロー結果も
  移管時の互換対象とし、契約側で変更する場合は別タスクにする。

## 3. 連番作成 (`sequentialNumberToolStripMenuItem_Click`)

ダイアログ初期値は開始 `1`、step `1`、skip off。開始と step は `Int32.Parse` し、
失敗時は「入力された値を数値に変換できませんでした.」を表示して変更しない。
対象は左端列、走査間隔は `Abs(step)` であり、選択末尾を超えるセルは書かない。

| ID | 入力（選択/開始/step/skip） | 期待出力 | Undo |
|---|---|---|---|
| S-01 | `["", "", "", ""]` / `1` / `1` / off | `["1", "2", "3", "4"]` | 1回で全セルを空へ戻す |
| S-02 | `["9", "", "8", ""]` / `10` / `2` / off | `["10", "", "11", ""]` | 上書きした0,2行だけを復元 |
| S-03 | 同上 / `10` / `2` / on | `["10", "", "12", ""]` | 同上 |
| S-04 | 4行 / `5` / `-2` / off | 0,2行へ `5`,`4` | 1 group |
| S-05 | 4行 / `5` / `-2` / on | 0,2行へ `5`,`3` | 1 group |
| S-06 | `A:B` を複数列選択 | A（左端）だけを更新し、Bは不変 | 1 group |
| S-07 | シート最終行を含む選択 / step `1` | 選択末尾まで更新し、範囲外へは書かない | 1 group |
| S-08 | step `0` | `step / Abs(step)` で `DivideByZeroException`。書き込み前なのでセルと Undo は不変 | 例外 |

**決定:** S-01〜S-07 は互換維持。S-08 は公開コマンドでは入力エラーとして拒否する
**別修正** とし、P5-002 のパラメーター検証、P5-004 の移管で扱う。

## 4. 置換 (`replaceToolStripMenuItem_Click`)

比較はカルチャ非依存の文字列完全一致（`==`）で、部分一致や正規表現ではない。
左端列だけを対象とし、空セルは読み飛ばす。`KARA` は通常文字列として扱われる。

| ID | 入力（選択/前/後） | 期待出力 | Undo |
|---|---|---|---|
| R-01 | `["1", "10", "1", ""]` / `1` / `X` | `["X", "10", "X", ""]` | 1回で2セルを復元 |
| R-02 | `["A", "a", KARA]` / `a` / `B` | `["A", "B", KARA]` | 1 group |
| R-03 | `["A", ""]` / `Z` / `B` | 不変。Undo 項目なし | なし |
| R-04 | 置換前 `""` | 警告「変換前指定がない.」、変更なし | なし |
| R-05 | 置換後 `""` | 警告「変換後指定がない.」、変更なし | なし |
| R-06 | `A:B` を複数列選択 | A（左端）だけを置換 | 1 group（該当時） |

**決定:** 全項目を互換維持する。

## 5. 反転 (`reverseToolStripMenuItem_Click`)

左端列の非空値だけを収集して逆順にし、元から非空だった位置だけへ戻す。
したがって空セルの位置は維持される。`KARA` は空ではなく通常の値である。

| ID | 入力 | 期待出力 | Undo |
|---|---|---|---|
| V-01 | `["1", "2", "3"]` | `["3", "2", "1"]` | 1回で復元 |
| V-02 | `["1", "", "2", "", "3"]` | `["3", "", "2", "", "1"]` | 1 group |
| V-03 | `["1"]` | 同じ値を書き込む group が1件作られる | Undo/Redoして表示値は同じ |
| V-04 | `["", ""]` | 不変。Undo 項目なし | なし |
| V-05 | `["1", KARA, "2"]` | `["2", KARA, "1"]` | 1 group |
| V-06 | `A:B` を複数列選択 | A（左端）だけを反転 | 1 group |

**決定:** 全項目（同値書き込みも含む）を互換維持する。

## 6. 四則演算 (`fourArithmeticOperationToolStripMenuItem_Click`)

入力を Trim した後、先頭1文字を演算子、残りを `Int32` として解釈する。
選択矩形を列優先で走査する。空セルと `KARA` は無視し、その他の非数値セルに
遭遇すると警告して return する。書き込み候補は全走査後に適用するため、
非数値エラーまでに計算済みの候補も適用されず、部分更新はない。

| ID | 入力（セル/式） | 期待出力 | Undo |
|---|---|---|---|
| A-01 | `["1", "-2"]` / `+3` | `["4", "1"]` | 1 group |
| A-02 | `["1", "-2"]` / `-3` | `["-2", "-5"]` | 1 group |
| A-03 | `["2", "-3", "0"]` / `*4` | `["8", "-12", "0"]`。0セルは書かない | 変更2件の1 group |
| A-04 | `["5", "-5", "0"]` / `/2` | `["2", "-2", "0"]`（整数除算）。0セルは書かない | 変更2件の1 group |
| A-05 | `["", KARA, "2"]` / `+1` | `["", KARA, "3"]` | 変更1件の1 group |
| A-06 | `["1", "X", "2"]` / `+1` | 警告「セルの値を数値に変換できませんでした.」、全セル不変 | なし |
| A-07 | `/0`、対象が非0セル | .NET の `DivideByZeroException`。候補適用前なので全セル不変 | 例外、Undo不変 |
| A-08 | `/0`、対象が0/空/KARAだけ | 対象を全て無視するため例外なし、変更なし | なし |
| A-09 | `*0`、対象セルが0 | 0セルを無視し、変更なし | なし |
| A-10 | 空/空白入力 | Trim 後の `val[0]` で `IndexOutOfRangeException` | 例外、Undo不変 |
| A-11 | `x1` | 演算子警告、変更なし | なし |
| A-12 | `+` または `+X` | 数値変換警告、変更なし | なし |
| A-13 | 複数列・複数行 | 全選択セルへ同じ演算を列優先で適用 | 1 group |

**決定:** A-01〜A-06、A-08〜A-09、A-11〜A-13 は互換維持。
A-07 と A-10 はクラッシュさせず入力エラーとして原子的に拒否する **別修正** とする。

## 7. 繰り返し入力 (`repeatNumberToolStripMenuItem_Click` / `HandleRepeatInput`)

### 7.1 起動とセッション

- メニュー選択時、左上セルへ同じ値を書き込む単独 Undo 項目（番兵）を作ってから、
  `RepeatInputBox` をモデルレス表示する。
- 初期値は開始 `1`、終了 `1`、行間隔 `1`、ループ `1`、スキップ `0`、挿入値は空。
- 実行ボタンごとに無条件で Undo 1回を行う。初回は番兵を、連続実行時は直前の
  `繰り返し` group を戻す。その後、**現在の** `selectRange` をクリアし、計算結果を
  同じ `繰り返し` group で書く。
- ダイアログを閉じてもイベント購読解除はなく、フィールド参照だけが残る。
  再起動時は新しい番兵と新しいダイアログを作る。

### 7.2 計算例

UI のスキップ値 `n` は内部で `n + 1` となる。番号カウンターは列の境界で
リセットされず、左列から右列へ継続する。書き込み対象は選択の高さではなく、
算出した `count` と行間隔で決まる。

| ID | 入力（開始..終了/間隔/loop/skip/挿入/選択） | 期待出力 | Undo |
|---|---|---|---|
| P-01 | `1..3` / `1` / `1` / `0` / 空 / A 3行 | A=`["1","2","3"]` | 1回で実行前選択内容へ戻す |
| P-02 | `1..3` / `2` / `1` / `0` / 空 / A | Aの相対行0,2,4へ `1,2,3`。選択範囲だけ先にクリア | 1 group |
| P-03 | `1..4` / `1` / `1` / `1` / 空 / A | `["1","3","1"]`（内部 skip=2、count=3） | 1 group |
| P-04 | `1..2` / `1` / `2` / `0` / 空 / A | `["1","2","1","2"]` | 1 group |
| P-05 | `1..2` / `1` / `1` / `0` / `X` / A | `["1","X","2","X"]` | 1 group |
| P-06 | P-01 / A:B | A=`["1","2","3"]`, B=`["1","2","3"]`。カウンターは折返して継続 | 1 group |
| P-07 | `1..2` / `1` / `1` / `0` / 空 / A:B | A=`["1","2"]`, B=`["1","2"]`（A終了時の折返し後にBへ継続） | 1 group |
| P-08 | `1..3` / `0` / `1` / `0` / 空 / A | 同一セルへ `1`,`2`,`3` の順で書き、最終値 `3` | 1 group内に重複書き込み |
| P-09 | `3..1` または loop `0` | countが0以下となり書き込みなし。選択範囲のクリアだけ実行 | クリアを1回で復元 |
| P-10 | 書き込み先がシート末尾を超える | 範囲検査がなく適用途中で例外になり得る。group は finally で閉じるが部分更新の可能性あり | 不定（既知不具合） |
| P-11 | 数値欄が非数値/空 | `Int32.Parse` 例外（ハンドリングなし）。実行前 Undo より先なのでセルと履歴は不変 | 例外 |

### 7.3 モデルレス再実行の再現手順

1. 任意の値がある範囲を選択してダイアログを開く（番兵が Undo に積まれる）。
2. P-01 を実行し、結果が `1,2,3` になることを確認する。
3. 同じダイアログで開始だけ `4` にして再実行する。直前 group が Undo された後、
   `4,5,6` に置き換わり、Undo 1回で手順1の値へ戻ることを確認する。
4. Redo 1回で `4,5,6` が戻ることを確認する。
5. ダイアログを閉じ、再度メニューから開く。新しい番兵が作られ、初回実行が
   その番兵だけを Undo することを確認する。

**決定:** P-01〜P-07 と既存セッション操作は移管時に互換維持する。
P-08 は host の重複変更拒否と衝突するため `step=0` を入力エラーにする **別修正**、
P-09 の逆順/非正 loop は入力エラーにする **別修正**、P-10 は全件事前検証で
原子的に拒否する **別修正**、P-11 は検証エラー表示にする **別修正** とする。

## 8. P5-002 以降への固定 Gate

1. P5-003/P5-004 の移管前後で、上表の「互換維持」行の出力と Undo group 数を一致させる。
2. 「別修正」行は characterization の期待値を黙って模倣せず、host/parameter validation の
   テスト名に元 ID（S-08、A-07、A-10、P-08〜P-11）を残す。
3. 外部コマンド結果は全変更を検証してから適用し、P-10 の部分更新を許容しない。
4. モデルレス session は任意のグローバル Undo ではなく、その session の直前結果だけを
   置き換える設計へ変更する。この安全化も P5-004 の明示的な仕様変更として扱う。
