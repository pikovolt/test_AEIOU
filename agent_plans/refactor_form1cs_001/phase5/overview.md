# Phase 5 Overview — 自動処理の外部拡張基盤

## 目的
`Form1` に直書きされている自動処理を、UI や `DataGridView` に依存しないコマンドとして段階的に分離し、最終的に外部 DLL から追加できる拡張ポイントを用意する。

初期移行対象は次の6経路とする。

- `fourArithmeticOperationToolStripMenuItem_Click`（四則演算）
- `reverseToolStripMenuItem_Click`（反転）
- `replaceToolStripMenuItem_Click`（置換）
- `repeatNumberToolStripMenuItem_Click`（繰り返しダイアログ起動）
- `HandleRepeatInput`（繰り返し入力実行）
- `sequentialNumberToolStripMenuItem_Click`（連番作成）

## 結論（計画時点）
外部 DLL を直接 `Form1` に接続せず、次の三層に分ける。

1. **Automation contract**
   - 選択範囲とセル値のスナップショットを受け取り、書き込み候補または検証エラーを返す。
   - WinForms、`Form1`、`DataGridView`、Undo 実装を参照しない。
2. **Automation host**
   - パラメーター入力、範囲外書き込み検査、書き込みの一括適用、Undo、再描画を担当する。
   - 拡張から返された結果を無条件には適用しない。
3. **Extension discovery**
   - `Extensions` ディレクトリの DLL から契約実装を明示的に探索・登録する。
   - 組み込み処理も同じ契約へ載せ、外部処理だけの別経路を作らない。

詳細は [`extension_contract.md`](extension_contract.md) を正とする。

## 採用理由
- 既存イベントハンドラーには「ダイアログ」「入力解析」「セル走査」「Undo」「描画」が混在しており、単純な別クラス化だけでは外部拡張にならない。
- 拡張へ生のモデルやコールバックを渡すと、範囲外更新、部分更新、Undo 不整合をホスト側で防げない。
- スナップショット入力 + 変更セット出力なら、組み込み処理をヘッドレスに検証でき、外部 DLL に対しても同じ検証境界を適用できる。

## スコープ
### 対象
- 上記6経路の現行挙動の固定とコマンド化。
- 小さな公開契約アセンブリと、組み込みコマンド登録機構。
- 外部 DLL の検出、契約バージョン検査、重複 ID 検査、例外分離。
- 既存メニューから同一 Automation host を呼び出す移行。

### 非対象
- スクリプト言語の埋め込み。
- NuGet やネットワーク経由の拡張配布・自動更新。
- 拡張 DLL のサンドボックス実行、署名検証、実行中 DLL のアンロード。
- 外部拡張による任意の WinForms UI 注入。
- 初期移行対象以外の編集機能の同時移管。

> 初版の外部 DLL は、利用者が配置した**信頼済みローカルコード**として扱う。安全でない DLL を隔離する機構ではない。

## 実行順
1. **P5-001 現行挙動の固定** — 6経路の入力・出力・Undo・空セル規則を characterization として記録する。
2. **P5-002 契約プロトタイプ** — 公開 DTO、コマンド、結果、パラメーター定義を確定する。まだ DLL 探索はしない。
3. **P5-003 単純変換の移管** — 置換、反転、四則演算を組み込みコマンドへ移す。
4. **P5-004 連番系の移管** — 連番作成と繰り返し入力を移し、モデルレスダイアログの Undo 規則を host へ閉じ込める。
5. **P5-005 host/registry 統一** — メニューと組み込みコマンドを registry 経由に統一し、結果検証を一元化する。
6. **P5-006 外部 DLL discovery** — `Extensions` 探索と障害分離を導入する。
7. **P5-007 回帰・運用文書** — smoke、サンプル拡張、配置・障害時の復旧手順を確定する。

依存順を飛ばして P5-006 から着手しない。現行挙動と host の検証境界が固定される前に外部コードをロードすると、回帰原因を切り分けられないためである。

## Phase5 完了条件
- 6経路のイベントハンドラーが、入力収集と host 呼び出しだけになっている。
- 組み込み処理が公開契約と同じコマンド面で動作する。
- 外部 DLL を追加・除去しても、拡張がない場合の既存機能が変化しない。
- 不正結果、重複 ID、契約不一致、コンストラクター/実行時例外がホストにより拒否され、シートが部分更新されない。
- `checklists/smoke_phase5.md` の必須項目が完了している。
