# task_PRE_003: VirtualMode起動前チェック（移行元: task_VM2_001）

## 目的
`DataGridView.VirtualMode` 有効化に着手する前提として、初期表示と基本操作の観点を明文化する。

## 実施内容
- `VirtualMode=true` 適用時に確認すべき観点（空白表示、例外、描画乱れ）を定義する。
- 既存イベント配線との干渉候補を洗い出す。
- IMPL着手時のチェック観点を引き継げる形で整理する。

## 完了条件
- VirtualMode有効化前に確認すべき観点が明記されている。
- IMPLタスク（`task_VM2_001.md`）に引き継ぐ前提が明記されている。
- 共通定義 `DONE_TEMPLATE_PRE.md` の必須欄がすべて記入済みである。

## 実装ゲートチェックリスト（`task_VM2_001.md` 引き継ぎ用）

| ID | チェック項目 | 優先度 (MUST/SHOULD) | 判定方法 |
| --- | --- | --- | --- |
| VM-PRE-01 | 初期表示で行・列ヘッダーおよび先頭表示セルが欠落しない。 | MUST | 目視確認（起動直後のグリッド全体を確認）。 |
| VM-PRE-02 | データ件数0件時に空表示が破綻せず、例外が発生しない。 | MUST | 手動操作（0件データで起動）＋ログ確認（例外ログなし）。 |
| VM-PRE-03 | 末尾行/末尾列に到達するスクロールで境界例外が発生しない。 | MUST | 手動操作（縦横スクロールを端まで実施）＋ログ確認。 |
| VM-PRE-04 | 編集確定後に再描画され、表示値と内部値が不整合にならない。 | MUST | 手動操作（編集→確定→再描画）＋目視確認。 |
| VM-PRE-05 | Undo/Redo後に表示内容・選択状態・編集状態の整合が維持される。 | MUST | 手動操作（編集→Undo→Redo）＋目視確認。 |
| VM-PRE-06 | 高速スクロール時にちらつき・空白セル・描画取りこぼしが顕在化しない。 | MUST | 手動操作（マウスホイール/スクロールバー連続操作）＋目視確認。 |
| VM-PRE-07 | 列ソート実行時に表示順が期待どおりで、再描画崩れがない。 | SHOULD | 手動操作（ソート昇順/降順切替）＋目視確認。 |
| VM-PRE-08 | 行選択変更時に関連UI（詳細ペイン等）が追従し、遅延しない。 | SHOULD | 手動操作（連続行選択）＋目視確認。 |
| VM-PRE-09 | フィルタ適用/解除時に表示件数・スクロール位置が破綻しない。 | SHOULD | 手動操作（フィルタON/OFF）＋目視確認。 |
| VM-PRE-10 | 列幅変更/並び替え後に表示が崩れず操作を継続できる。 | SHOULD | 手動操作（列幅ドラッグ/列順変更）＋目視確認。 |
| VM-PRE-11 | 画面リサイズ時に表示再計算が破綻せず、操作不能にならない。 | SHOULD | 手動操作（ウィンドウ拡大/縮小）＋目視確認。 |
| VM-PRE-12 | 既存イベント配線（SelectionChanged等）と干渉せず重複処理が起きない。 | SHOULD | ログ確認（イベント発火回数）＋手動操作。 |
