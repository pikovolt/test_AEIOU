# Smoke Checklist: VirtualMode 回帰観点

> このチェックリストは `impl` 完了判定専用。
> `pre` タスクでは参照不要（実施対象外）。

## 編集系
- [x] セル編集開始/確定/キャンセルが期待通り動作する（VM2-003 で確認: 確定時のみ反映、キャンセル時は未反映）
- [x] Undo/Redo 後に表示とデータが一致する（VM2-007 で確認: 単一セル/範囲編集とも往復整合）
- [x] 連続入力時にフォーカス遷移が破綻しない（VM2-005 で確認: キーボード移動と選択整合維持）

## 描画系
- [x] スクロール時に表示崩れ・ちらつきがない（VM2-001/002/006 で確認: 初期表示崩壊なし、欠落再現なし、ちらつき悪化なし）
- [x] 選択範囲ハイライトが正しく追従する（VM2-005/006 で確認: 選択変更時の表示破綻なし）
- [ ] 色/スタイル適用が既存仕様どおり反映される（未実施: VM2 範囲外、UIスタイル回帰の専用観点未実行）

## データ整合性
- [x] 行列境界での入力/削除が例外なく処理される（VM2-004 で確認: 0件↔増減遷移時に件数ズレ例外なし）
- [ ] 大量データ時でも編集結果が欠落しない（一部未実施: 大規模・高負荷の定量検証は未完了）
- [ ] 保存/再読込で表示内容が再現される（未実施: Save/Load 回帰は Phase2 の実施対象外）

## 操作系
- [x] キーボードショートカットが既存仕様どおり機能する（VM2-005/007 で確認: 移動・Undo/Redo の主要ショートカット成立）
- [x] マウス選択・ドラッグ操作が退行していない（VM2-005 で確認: マウス選択後も整合維持）
- [ ] コンテキストメニュー操作が正しい対象に作用する（未実施: コンテキストメニュー回帰は今回証跡なし）
