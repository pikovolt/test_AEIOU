# Smoke Checklist: VirtualMode 回帰観点

## 編集系
- [ ] セル編集開始/確定/キャンセルが期待通り動作する
- [ ] Undo/Redo 後に表示とデータが一致する
- [ ] 連続入力時にフォーカス遷移が破綻しない

## 描画系
- [ ] スクロール時に表示崩れ・ちらつきがない
- [ ] 選択範囲ハイライトが正しく追従する
- [ ] 色/スタイル適用が既存仕様どおり反映される

## データ整合性
- [ ] 行列境界での入力/削除が例外なく処理される
- [ ] 大量データ時でも編集結果が欠落しない
- [ ] 保存/再読込で表示内容が再現される

## 操作系
- [ ] キーボードショートカットが既存仕様どおり機能する
- [ ] マウス選択・ドラッグ操作が退行していない
- [ ] コンテキストメニュー操作が正しい対象に作用する
