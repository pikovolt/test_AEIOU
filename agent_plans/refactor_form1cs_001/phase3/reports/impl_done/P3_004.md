# P3-004: Extract Cell Value Operations

## 目的
`Form1.cs`でのセル値追加・編集・削除にまつわるUndo/Redo呼び出しを含むロジックを分離し、セルの操作に関連する責務をカプセル化する。

## 実施内容
- `IGridCellValueService` とその実装 `GridCellValueService.cs` を新規作成。
- セルの変更処理である `InsertNumber`, `ApplyValue`, `InsertEmptyCell` をこのサービスに集約。
- `Form1.cs` でこのサービスを初期化し、`OnNumberKey`, `OnAddKey`, `OnSubtractKey`, `OnDecimalKey` などから呼び出すようにリファクタリングを実施。
- `AEIOU.csproj` の更新。

## 検証結果
- 静的解析によりロジックの移動が正しく行われていることを確認。`OperationGroup` の開始・終了、およびアンドゥ情報の登録処理が正常に移管されている。
