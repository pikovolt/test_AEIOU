# Phase 3 Smoke Test Protocol

## 目的
Phase 3 (表示・入力責任分離) のリファクタリングが既存の動作を破壊していないか、機能レベルで確認する。自動化されたテストが無いため、UI上の手動テストとなる。

## 前提条件
- `AEIOU.csproj`が正常にビルドできること (開発環境にて)
- アプリケーションがエラーなく起動すること

## テスト項目一覧

### 1. セルヘッダー描画 (P3-001)
- [x] タイムシート左端のフレーム番号（1, 2, 3...）が正しく描画されているか
- [x] シート境界（デフォルトなら6秒＝144フレームごと）の開始時に `[1]` のようなシート表記が正しく行われるか

### 2. 基準線描画 (P3-002)
- [x] 1秒ごと、あるいは指定フレームごと（設定による）のグリッド線の太さ・色が正しく切り替わって描画されているか
- [x] コマの「切り貼り」が発生した場合でも、基準線の描画がずれないか

### 3. キーボード入力ルーティング (P3-003, P3-004)
- [x] 矢印キー (`↑`, `↓`, `←`, `→`) でのカーソル移動が正しく行われるか
- [x] `Shift + 矢印キー` での範囲選択拡大・縮小が正しく行われるか
- [ ] `Home` / `PageUp` / `PageDown` での画面スクロール・カーソル移動が正しく行われるか
- [ ] 数字キー (テンキーおよびフルキー) でセルに値が入力されるか
- [ ] `+` キーで「直前の値＋１」、`-` キーで「直前の値－１」が正しく入力されるか
- [x] `*`, `/` での選択範囲の増減が正しく行われるか
- [x] `.` で空セル記号が正しく入力されるか
- [ ] `Insert`, `Delete`, `BackSpace` が意図通りに動作し、かつ、Undo/Redoが可能か

### 4. マウス操作 (P3-005)
- [x] マウスの左ボタンドラッグによる範囲選択が正しく行われるか
- [x] 選択後、別の場所にドラッグ＆ドロップしての「カット＆ペースト」(移動)が動作するか
- [ ] `Ctrl` キーを押しながらのドラッグ＆ドロップで「コピー＆ペースト」が動作するか
