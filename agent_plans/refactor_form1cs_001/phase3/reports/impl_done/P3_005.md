# P3-005: Clean Up Remaining Mouse Handlers

## 目的
`Form1.cs`内のマウスによる範囲選択やドラッグ＆ドロップ（カット＆ペースト/コピー＆ペースト）操作のロジックを抽出し、UIイベント処理の責務を分離することでコードを整理する。

## 実施内容
- `IGridMouseService` インターフェースと `GridMouseEventHandler.cs` を新規作成。
- セルのMouseDown, MouseMove, MouseUp処理を移管。
- `Form1.cs` に `GridMouseEventHandler` のインスタンスを生成し、各マウスイベントハンドラの中身を委譲するよう修正。
- `AEIOU.csproj` の更新

## 検証結果
- 静的解析によりロジックの移動が正しく行われていることを確認。ドラッグ時の描画フラグ (`isRectDrag`) や選択範囲情報の更新処理が正常に引き継がれていることを確認。
