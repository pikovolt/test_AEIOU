# Smoke Checklist: Phase3（描画分離＋入力分離）

## 描画系
- [ ] CellPainting で表示崩れ・ちらつきが増加していない
- [ ] フレーム番号描画が既存仕様どおり表示される
- [ ] 境界線判定（連続状態境界）が既存仕様どおり反映される

## 入力系
- [ ] キーボード移動（上下左右・範囲選択）が既存仕様どおり機能する
- [ ] 数字入力・空セル入力が既存仕様どおり反映される
- [ ] Undo/Redo 往復後に表示とデータが一致する

## データ整合性
- [ ] 行列境界での入力/削除が例外なく処理される
- [ ] 保存/再読込で表示内容が再現される

## 操作系
- [ ] マウス選択・ドラッグ操作が退行していない
- [ ] コンテキストメニュー操作が正しい対象に作用する
