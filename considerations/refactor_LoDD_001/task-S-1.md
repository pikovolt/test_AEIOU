# task-S-1: 防壁テーブルの実現手段が不正確

## ステータス
- **状態**: 未了
- **更新日**: 2026-03-07

## タスク概要
v1.1 の6つの防壁テーブルで、6番目「AI負債の可視化」の実現手段が `Debt Markers + 返済スプリント` とある。これはAI負債管理の手段であり、セマンティックドリフト検知の手段ではない。元文書では `Contract Test + Merge Gate` と明記されている。防壁テーブルにセマンティックドリフトが含まれていないか、混同が起きている。

## 詳細分析

### 現状の問題
- **v1.1での記載**: 6番目の防壁「AI負債の可視化」の実現手段が `Debt Markers + 返済スプリント` と記述されている
- **実現手段の混同**: この手段はAI負債の可視化と管理を目的とするもので、セマンティックドリフトの検知や防止を直接の目的としていない
- **元文書での定義**: 統合元の議論文書「Semantic Drift Issues in Agent Parallelization.md」では、セマンティックドリフト検知の手段として `Contract Test + Merge Gate` と明記されている
- **概念上の矛盾**: 防壁テーブル内でセマンティックドリフト対策とAI負債対策の手段が混在・混同している可能性がある

### 影響範囲
- `LoDD_Reference_v1.1.md` の防壁テーブル（6つの防壁を定義するセクション）
- セマンティックドリフト対策の実現手段の正確性
- AI負債管理の実現手段の正確性
- v1.1を参照する実装者の理解の正確性

## 対応方針

### 確認項目
1. 元文書「Semantic Drift Issues in Agent Parallelization.md」で定義されている防壁とその実現手段を確認
2. v1.1 の6つの防壁テーブル全体を見直し、各防壁の目的・手段の正確性を確認
3. セマンティックドリフト防止とAI負債管理の責務分離が適切に表現されているか確認
4. 「Contract Test + Merge Gate」の具体的な実装方法が v1.1 に十分に記載されているか確認

### 修正対象
- `LoDD_Reference_v1.1.md` の防壁テーブル定義
- 必要に応じて、セマンティックドリフト検知の実行ガイダンス
- 6番目の防壁が「セマンティックドリフト検知」なのか「AI負債の可視化」なのか、またはどちらも必要かの整理
