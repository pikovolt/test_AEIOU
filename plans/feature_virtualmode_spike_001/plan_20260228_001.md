## 目的
`DataGridView` の `VirtualMode = true` 移行に向けた最大の不確実性（接続性と性能）を、本流のロジックから切り離して検証する。
同時に、Phase 1で課題となった「性能KPI（P95 <= 25ms）の測定プロトコル」を先行して確立する。

## スコープ
- 対象: `Form1.cs` 内の `DataGridView` 初期化処理、および性能測定用の一時コード
- 非対象: 実モデル（`TimingSheetModel`）との結合、既存の Undo/Redo 操作の完全な互換性維持（本スパイクではダミーデータを用いるため）

## 実行ステップ（順守すること）

- [ ] **1. 性能測定プロトコルの先行実装 (最優先)**
  - [ ] `System.Diagnostics.Stopwatch` を用いた測定用ヘルパーメソッド（またはクラス）を一時的に追加。
  - [ ] 入力イベント（`KeyDown` 等）の先頭で計測開始し、`CellPainting` または画面更新完了（`Application.DoEvents` 後など、適切なフックポイント）で計測終了する仕組みを作る。

- [ ] **2. ダミーデータソースの準備**
  - [ ] 検証用の単純な2次元配列（または `List<List<string>>`）を `Form1` 内に一時定義する（C# 3.0構文に準拠）。

- [ ] **3. VirtualModeの疎通確認**
  - [ ] `dataGridView1.VirtualMode = true;` を設定。
  - [ ] `CellValueNeeded` イベントをハンドリングし、ダミーデータを高速に返す。
  - [ ] `CellValuePushed` イベントをハンドリングし、ダミーデータを更新する。

- [ ] **4. 性能測定の実行 (手動検証)**
  - [ ] 以下のシナリオで P95 を計測し、`worklog_20260228_001.md` に結果を記録する。
    - シナリオA: 単一セルの値変更（文字入力）
    - シナリオB: 矢印キーによる連続したセル移動（スクロール伴う）

## 完了条件 (Exit Gates)
- [ ] `VirtualMode = true` の状態でアプリケーションがクラッシュせず起動すること。
- [ ] ダミーデータの表示、およびセル編集によるダミーデータの更新がエラーなく行えること。
- [ ] P95 の測定結果（ms）が計測され、ログに記録されていること。
