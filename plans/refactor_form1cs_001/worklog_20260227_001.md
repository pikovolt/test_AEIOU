## 7. 移譲ロジック再確認（PRレビュー反映）

- `calcRect_with_enter` の移譲で、元実装にあった `ClearSelection()` の実行タイミングが変わっていた点を確認。
- 元動作に合わせるため、`Form1.calcRect_with_enter` 側で **len算出前に常に `ClearSelection()`** するよう修正。
- 併せて `GridSelectionService.MoveSelectionDown` から `ClearSelection()` を外し、
  「呼び出し側が選択クリア責務を持つ」構造に整理。


## 8. A-4 / A-5 追加実装ログ（2026-02-27）

### 8-1. A-4: 選択更新ロジックの段階委譲
- `GridSelectionService` に `MoveSelection(Rect rect, int x, int y)` を追加。
- `Form1` の矢印キー移動や同等の選択範囲更新処理で、
  `CurrentCell` 設定 + 二重ループによる `Selected=true` をサービス呼び出しへ置換。
- 既存 `MoveSelectionDown` は新メソッドを内部利用する形に整理。

### 8-2. A-5: `CellPainting` の renderer 分離
- `GridCellRenderer` を新規追加。
  - `ApplyTimingCellState(...)`: `TimingCell` の `BorderState` / `IsKaraCell` / `IsContinuousLine` を設定
  - `PaintCell(...)`: `e.Paint(...)` と `e.Handled=true` を実行
- `Form1.dataGridView1_CellPainting` では、
  - 背景色判定は既存 `GridCellStyleResolver`
  - `TimingCell` 状態更新 + 実描画は `GridCellRenderer`
  へ委譲する構成に変更。

### 8-3. 補足
- 既存動作維持を優先し、描画アルゴリズム自体（`calcBorderState`, `checkContinuty`）はそのまま。
- `AEIOU.csproj` に `GridCellRenderer.cs` を追加。
